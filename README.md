A short poem about agency — the power to choose and to act — written by
`main.py` (Python 3.13, standard library only, no network) to
`/output/entry.txt`. The text is fixed, so two runs produce identical bytes.

The poem: two agents meet at a fork. Neither gives up their hand; they lay
both, by choice rather than by chain, on the same map — one road, twice
chosen. Agreement, here, is not the surrender of agency but its doubling.

## Run it

```sh
python3 main.py   # writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt)
```
